## Why does this repository exist?

Because learning programming isn't always about building a perfect project.

Sometimes it's:

```text
Idea
 ↓
Code
 ↓
It doesn't work
 ↓
Google
 ↓
Try again
 ↓
It works
 ↓
"why does it work?"
 ↓
Learn something new
```

So instead of deleting the old experiments, I keep them here.

This repository is basically a record of my progress as I learn more about programming and computer science.
